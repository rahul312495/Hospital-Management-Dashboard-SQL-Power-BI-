##  Hospital Management Dashboard (SQL + Power BI)

### Overview

This project is a **Hospital Management Dashboard** built using **SQL and Power BI**, designed to analyze and visualize hospital operations including patients, doctors, medicines, and financial data.

It demonstrates strong skills in:

* SQL (joins, aggregations, filtering)
* Data modeling
* Interactive dashboard design in Power BI
* Business insights generation

---

### Tech Stack

* **SQL** – Data extraction, transformation, joins
* **Power BI** – Dashboard creation & visualization
* **DAX** – Measures and calculated columns
* **Data Modeling** – Relationships between tables

---

### Dataset Description

The project uses structured hospital data including:

* Patients
* Doctors
* Appointments
* Medicines
* Billing & Finance
* Hospital Infrastructure

---

### Key Features

#### 🔹 1. Patient Dashboard

* Patient details (Name, Age, Diagnosis, Status)
* Admission & discharge tracking
* Medicine consumption analysis
* Billing summary
* Heatmap for medicine usage

---

#### 🔹 2. Doctor Dashboard

* Doctor profile (ID, specialization, salary)
* Availability status
* Appointments tracking
* Revenue generated per doctor
* Commission insights

---

#### 🔹 3. Hospital Dashboard

* Patient records table with:

  * Status (Admitted/Discharged)
  * Surgery notes & reasons
* Bed distribution (General vs Private)
* Patient age group analysis
* Surgery scheduling overview

---

#### 🔹 4. Finance Dashboard

* Total revenue & billing amount
* Patient charges breakdown:

  * Surgery
  * Room
  * Tests
  * Medicines
* Monthly medicine sales trend
* Stock vs sales comparison

---

#### 🔹 5. Medicine Dashboard

* Medicine stock vs sales analysis
* Category-wise distribution
* Quantity tracking
* Inventory insights

---

###  Interactive Features

#### Slicers

* **Patient Slicer** → Filter by individual patient
* **Doctor Slicer** → Filter by doctor
* Dynamic filtering across all visuals

---

####  Drill Through

* Navigate from summary → detailed report
* Example:

  * Medicine → detailed medicine analysis
  * Patient → individual patient report

---

####  Tooltips

* Custom tooltips for deeper insights on hover
* Helps avoid clutter while still showing detailed info
